# Project 1 — Kitchen Equipment Sales Analysis

### Overview

This project demonstrates an end-to-end data analytics process using a kitchen equipment sales dataset. The analysis includes data cleaning, SQL-based business analysis, and dashboard visualization.

### 🛠 Tools

- Microsoft Excel
- Google BigQuery
- SQL
- Google Looker Studio

### Project Workflow

```
Raw Data
      ↓
Data Cleaning (Excel)
      ↓
Business Analysis (SQL)
      ↓
Dashboard Development
      ↓
Business Insights
```

### Business Questions

- Total shipping cost and average shipping fee
- Top selling products
- Revenue analysis (Q4)
- Refund analysis
- Sales by city
- Category performance
- Product contribution
- Customer purchasing behavior
- Refund rate by city
- Revenue optimization

### Dashboard Preview

Dashboard is available in:

```
kitchen-equipment-sales-analysis/Dashboard
```

### Key Insights

- Q4 generated the highest completed revenue.
- Alat Masak category contributed the highest sales.
- Jakarta became the city with the highest sales.
- Refund transactions represented only a small percentage of total sales.
- Several cities showed higher refund rates and require further evaluation.
